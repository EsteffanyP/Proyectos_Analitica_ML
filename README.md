# Proyectos de Analítica y Machine Learning

Repositorio con ejercicios y proyectos aplicados de analítica de datos y machine learning, desarrollados durante mi formación en analítica de datos en la Universidad de Antioquia.

## Contenido

| Notebook | Descripción | Técnicas / herramientas |
|---|---|---|
| [`Aprendizaje supervisado.ipynb`](./Aprendizaje%20supervisado.ipynb) | Clasificación de riesgo crediticio (predicción de incumplimiento de préstamos) en el sector bancario | Label/One-Hot Encoding, selección de variables (RFE, Lasso), XGBoost, Random Forest, GridSearchCV |
| [`Redes neuronales.ipynb`](./Redes%20neuronales.ipynb) | Detección de fraude en transacciones con tarjeta de crédito | Red neuronal (Keras), Keras Tuner (RandomSearch), regresión logística como comparación, optimización de recall |
| [`Deep Learning en Sector Financiero.ipynb`](./Deep%20Learning%20en%20Sector%20Financiero.ipynb) | Modelo de clasificación sobre capacidad de pago de clientes usando redes neuronales artificiales | Preprocesamiento, balanceo de clases, redes neuronales |
| [`Clustering.ipynb`](./Clustering.ipynb) | Segmentación de países según indicadores socioeconómicos y de salud | K-Means, Clustering Jerárquico, DBSCAN, PCA, winsorización |
| [`Preparación y visualización de datos.ipynb`](./Preparaci%C3%B3n%20y%20visualizaci%C3%B3n%20de%20datos.ipynb) | Limpieza y preparación de datos para la construcción de un dashboard | Redefinición y eliminación de variables, tratamiento de fechas |
| [`Tratamiento de direcciones.ipynb`](./Tratamiento%20de%20direcciones.ipynb) | Limpieza y estandarización de una base de datos de registros ambientales (direcciones, NIT, fechas) | Manejo de datos duplicados y faltantes, estandarización de variables |
| [`BD relacional GeoJSON.ipynb`](./BD%20relacional%20GeoJSON.ipynb) | Construcción de una base de datos integrada de municipios de Colombia a partir de fuentes dispersas (Excel + GeoJSON) para un programa de cooperación internacional | Pandas, GeoJSON, cálculo de distancias geodésicas (Haversine), merge de bases de datos |

## Librerías
Python · Pandas · Scikit-learn · XGBoost · Keras/TensorFlow · SQL
