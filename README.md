# Proyectos de Analítica y Machine Learning

Repositorio con ejercicios y proyectos aplicados de analítica de datos y machine learning, desarrollados como parte de mi formación en la Universidad de Antioquia.

## Contenido

| Notebook | Descripción | Técnicas / herramientas |
|---|---|---|
| [`Aprendizaje supervisado.ipynb`](./Aprendizaje%20supervisado.ipynb) | Modelo de clasificación de riesgo crediticio a partir de datos financieros y demográficos de clientes | Codificación de variables categóricas, selección de variables (RFE, Lasso), normalización |
| [`Clustering.ipynb`](./Clustering.ipynb) | Segmentación de datos mediante aprendizaje no supervisado | K-means, análisis de clusters |
| [`Redes neuronales.ipynb`](./Redes%20neuronales.ipynb) | Modelo de red neuronal aplicado a un problema de clasificación/predicción | Redes neuronales, TensorFlow/Keras |
| [`Deep Learning en Sector Financiero.ipynb`](./Deep%20Learning%20en%20Sector%20Financiero.ipynb) | Aplicación de deep learning a un caso del sector financiero | Redes neuronales profundas |
| [`Preparación y visualización de datos.ipynb`](./Preparaci%C3%B3n%20y%20visualizaci%C3%B3n%20de%20datos.ipynb) | Limpieza, transformación y exploración visual de un conjunto de datos | Pandas, Matplotlib/Seaborn |
| [`Tratamiento de direcciones.ipynb`](./Tratamiento%20de%20direcciones.ipynb) | Procesamiento y estandarización de datos de direcciones | Limpieza de texto, geolocalización |
| [`BD relacional GeoJSON.ipynb`](./BD%20relacional%20GeoJSON.ipynb) | Trabajo con datos geoespaciales y estructuras de bases de datos relacionales | GeoJSON, SQL |

## Tecnologías

Python · Pandas · Scikit-learn · TensorFlow/Keras · SQL
